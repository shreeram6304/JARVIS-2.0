# 🤖 JARVIS 2.0

### AI Voice Assistant developed by Sriram Darakonda

A cross-platform AI voice assistant built with Python and the Gemini Live API. JARVIS 2.0 enables natural voice conversations, system automation, file processing, web search, and desktop control through a single intelligent interface.

---

# ✨ Overview

JARVIS 2.0 is a real-time desktop AI assistant designed to improve productivity through voice interaction and automation. It combines conversational AI with computer control, allowing users to interact naturally while performing everyday tasks such as launching applications, searching the web, controlling the operating system, summarizing files, and assisting with programming.

The project focuses on creating a responsive, extensible, and cross-platform assistant that can evolve into a complete personal AI system.

# 📦 Installation

Clone the repository

```bash
git clone https://github.com/shreeram6304/JARVIS-2.0.git
```

Open the project

```bash
cd JARVIS-2.0
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python main.py
```
